## 기능 (자동 탑 관련)

- 자동 탑 등반(自动爬塔): 시작 위치, 횟수, 속성 탑, 잠재력 선택 모드, 잠재 리롤 최대 횟수,
  상점/강화 커스텀 옵션, 선택지(이벤트) 전략 파일, 탑 목표 설정.
- **단, 공식 설명에 "자동 탑은 일일/주간 숙제용이고 기록(점수) 경쟁용은 손으로 하라"고 적혀 있다.**
  규칙에 안 걸리면 게임의 "추천" 카드를 집는 수준. 우리 봇(조건 맞는 고득점 도자기 공장)과 목적이 다르다.
- 그 밖에: 로그인/출석, 활동 정리, 선물, 위임, 임무 수령 등 숙제 자동화.

## 잠재력 우선순위 JSON (걔네 규칙 언어)

규칙 목록을 위에서부터 보고, 제시된 카드 중 "순위가 가장 높은 것"을 집는다. 아무 규칙도 안 걸리면 게임 추천.
규칙 필드:

| 필드 | 뜻 | 우리 봇의 대응물 |
|---|---|---|
| `potential` (이름 또는 목록) | 이 잠재면 집기. 목록이면 같은 순위 (跨度 큰 쪽 먼저) | 프리셋 표시(필수/다다익선...) + 점수 |
| `trekker` | 캐릭터 소속 (개수 세기용) | char_of |
| `level_span` | 이번에 오르는 레벨 ≥ N일 때만 | gain (점수에 자동 반영) |
| `max_level` | 지금 레벨 < N일 때만 (예: 1 = 명함만) | 명함만 표시, max_scored_level |
| `refresh` | 이번 화면에서 리롤 N번 이상 했을 때만 (고집 낮추기) | MAX_REROLLS_KEEP 뒤 "덜 나쁜 것" |
| `condition` | 가진 잠재 레벨/캐릭터별 보유 종수 조건 (AND/OR) | 필수 찾기, 캐릭터 막힘(char_locked), _mains_high |
| `priority` | 순위를 숫자로 직접 지정 | 점수 |
| `no_upgrade`/`no_enhance`/`max_level_span` | 레벨업 제외 / 강화머신에서 제외 / 跨度 상한 | - |

## 눈여겨볼 것

1. **"867 打法"**: 지원 캐릭터 잠재를 8종류 "명함만" 깔고(안 올림), 그다음 메인 키 잠재를 올리는 커뮤니티
   정석 빌드가 있다. `count_at_least: 8` 조건으로 구현. — 사용자가 설명한 "보라+금 잠재 6개 이상이고 6렙
   미만 2개 이상이면 그 캐릭터 새 잠재가 안 뜸" 메커니즘과 연결되는 운영법으로 보인다.
2. **규칙을 코드가 아니라 사용자 편집 JSON으로** 두는 설계. 우리는 규칙이 코드에 있는데, 프리셋마다 달라지는
   부분(동점 순서, enhance_first, 시작 층...)이 늘면 이런 프리셋별 규칙 파일로 빼는 걸 고려할 만하다.
3. 선택지(이벤트)도 전략 파일로 빼놨다 (事件选项策略).
4. 리롤 뒤에만 켜지는 규칙(`refresh`)은 "몇 번 리롤해 보고 안 나오면 눈높이 낮추기"를 선언적으로 표현한 것.
