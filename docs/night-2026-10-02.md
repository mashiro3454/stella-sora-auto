# 2026-10-02 밤샘 실행 기록

사용자가 자는 동안(02시~) 봇을 실제 모드(650원 도박 포함)로 돌리면서 문제를 고친 기록.
숫자는 `python tools/night_report.py logs/night1.log`로 다시 볼 수 있다.

## 새로 된 것

- **기록 저장**: 20층이 끝나면 기록 이름을 저장한 시각(`1002_0158`)으로 바꾸고 저장. 점수와 버릴 조건은
  `logs/records.jsonl` 장부에. 분해는 하지 않는다 (되돌릴 수 없어서). 흐름은 `stella_auto/record.py` 맨 위.
- **20층**: 보스 뒤 마지막 상점에 들르고, 남은 돈으로 소리까지 산다.
- **소리 구매**: 상점에서 B(가방) → 레코드 스킬 탭에서 협주스킬별 필요한 소리를 그림 색으로 읽어서
  사용자 규칙대로 산다 (`stella_auto/notes.py`). 바람 프리셋: 바람 소리 협주 6개, 필살기·강공 3개, 행운 2개, 집중 1개.
- **지도 기억**: NPC/상점/강화머신 자리도 기억. 5·12·19층은 같은 지도라 강화머신과 상점으로 바로 간다.
  2층과 16층 선택의 방도 같은 지도였다.
- **판 상태 저장**: `logs/run_state.json`. 봇을 다시 켜도 같은 판(가진 잠재, 650원 성공)을 이어 간다.
- **봇이 도는 동안 절전/화면 꺼짐 막기** (봇이 끝나면 풀림).
- `logs/pause_at_menu` 파일을 만들면 다음에 출발 화면에서 멈춘다.

## 밤새 고친 문제 (전부 main에 올림)

| 문제 | 고친 것 |
|---|---|
| 20층 카드 화면에서 봇을 켜니 1층 규칙으로 리롤 5번 → 판 포기 | 중간에 켠 판은 재시작/리롤 판단 안 함 |
| ESC 지도에서 층을 못 읽고 1층으로 둔 뒤 19층을 2층으로 셈 | 세 번 시도, 못 읽으면 다음 제목의 층을 그대로 믿음, 지도 전체 읽기 |
| 새 판 1층 제목 "1/20층"을 "11층"으로 읽어 2층으로 셈 | 방금 층이 바뀌고 로딩도 안 봤으면 무시 |
| 로딩 화면에서 켠 봇이 메뉴로 착각해 3분 기다림 | 화면이 자리 잡을 때까지 기다림 |
| 15층 하늘색 고리 출구 문양을 못 찾음, HUD 가림 영역이 너무 넓음 | 다음 방 색 고리로도 찾기, HUD 영역 좁힘 |
| 무늬를 출구로 알고 그 앞에서 서성임 (11, 16층) | 가 봐서 로딩이 안 되면 가짜 문, 여러 번 나가 본 출구와 먼 문양 무시 |
| 문 바로 앞에서 틀어진 기억 자리로 가려 함 (3층) | 문 앞에서는 화면 문양으로 자리 다시 잡기 |
| 5층 거래의 방: 강화 글자를 NPC로, 상점을 찾다 출구로 나감, 상점 NPC를 포기 목록에 | 강화 글자 제외, 출구 문양이 보이면 피하고 멈춤, 출구 옆 멈춤은 포기 아님 |
| 반값 소리(45원)를 72원으로 읽어 안 삼, "×15"를 "%15"로 읽어 5개짜리로 삼 | 큰 가격만 따로 읽기, 개수 읽기 고침 |
| 선택지 4개 중 2개만 읽음 (긴 보기 글자) | 상자 오른쪽 끝으로 상자 찾기 |
| 퀴즈 보기가 다 나오기 전에 읽어 틀린 답 | 정답 보기가 보일 때까지 기다림 |
| 모르는 선택지에서 140원짜리 소리 구매, 공짜 선택지("획티" 오타) 놓침 | 다 돈이 들면 ESC, "지금은 안 돼"(효과 없음) 고르기, 오타 처리 |
| 650원 결과를 돈 숫자 한 자리 빠진 OCR로 판정할 위험 | 화면 알림 글자 + 여러 번 읽은 돈 |
| 이름 바꾸기 창을 못 알아봐서 첫 완주 기록이 "이름 없는 기록"으로 저장됨 | 창을 더 기다리고 다시 시도 |
