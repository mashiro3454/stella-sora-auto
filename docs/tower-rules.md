# 별의 탑 규칙과 선택 알고리즘 (작성 중)

출처: 사용자 설명(2026-10-01)과 녹화 영상 3개(2026-10-01) 확인 결과.
`[?]`는 아직 확인이 필요한 부분.

## 기본

- 게임 창: 1920×1080 창모드로 고정.
- 탑/난이도: 사용자가 지정. 속성에 맞춰 물/바람, 불/어둠, 빛/땅 중에 고른다.
- 탑 입장에 드는 자원은 없다. 무한히 돌 수 있으니 재시작을 아끼지 않는다.
- **빠른 전투 버튼은 절대 누르지 않는다.**
- 자동전투는 전투만 대신해준다. 전투가 끝나면 WASD로 캐릭터를 움직여서 다음 층으로 간다.
- 다른 창(메신저 알림 등)이 게임 창 위를 덮는 경우가 영상에 있었다. 캡처할 때 주의.

## 층 구성 (20층)

| 페이즈 | 층 | 방 순서 |
|---|---|---|
| 1 | 1–6 | 전투 / 선택 / 전투 / 강적 / 상점 / 보스 |
| 2 | 7–13 | 전투 / 강적 / 선택 / 전투 / 강적 / 상점 / 보스 |
| 3 | 14–20 | 전투 / 강적 / 선택 / 전투 / 강적 / 상점 / 보스+상점 |

- 상점은 5, 12, 19층, 그리고 20층 보스 뒤. 모두 4번.
- 게임 속 방 이름: 전투의 방, 선택의 방, 강적의 방, 거래의 방, 리더의 방.
- ESC 메뉴에 지금 층("1/20층 전투의 방")과 앞으로 나올 방이 지도로 나온다. 층 확인에 쓸 수 있다.

## 층 이동

- 출구는 보통 입구 반대쪽에 있다.
- 출구에서 너무 멀어지면 화면에 출구 방향 표시가 뜬다.
- 상호작용 키는 없다. 출구 안으로 걸어 들어가면 된다.

### 실험 결과 (2026-10-01, 불꽃과 먼지 난이도 8, 1층 전투의 방)

봇 입력(`stella_auto/input.py`)만으로 1층 출구까지 걸어가서 2층으로 넘어가는 데 성공했다.

- **조작:** WASD는 화면 기준이다 (W 위, A 왼쪽, S 아래, D 오른쪽, 두 개 같이 누르면 대각선).
  카메라는 캐릭터가 가운데에서 좀 벗어나야 따라온다. 그래서 짧게 누르면 겉보기 방향이 휘어 보인다.
- **캐릭터 위치:** 발밑 초록 체력바(칸 5개, 한 칸 폭 25–30px, 높이 11px)로 찾는다. 화면에 이런 모양은 이것뿐이었다.
- **출구가 화면 밖일 때:** 화면 가장자리에 청록색 문 아이콘이 뜨고, 옆의 작은 삼각형이 출구 방향을 가리킨다.
  캐릭터 발밑에도 바라보는 방향을 나타내는 청록 화살표가 있으니 헷갈리지 않게 뺀다.
- **출구가 화면 안일 때:** 가장자리 표시는 사라진다. 출구 문에는 파란 원 문양이 빛난다.
- **장애물:** 테이블 같은 데 막히면 제자리걸음을 한다 (실험에서 6번 연속 위치가 같았음). 막히면 옆으로 돌아가야 한다.
- **출구 문:** 문 안에 **다음 방 종류 문양**이 떠 있다 (ESC 지도 아이콘과 같다).
  노란 고양이 = 전투의 방, 파란 상자 = 선택의 방, 빨간 문양 = 리더의 방(거래의 방 왼쪽 위 문에서 봄).
  문양은 반투명이라 흐리고, 흰 테두리가 문 안쪽 밝은 바닥과 붙어 보일 때가 있다.
  문 안으로 걸어 들어가면 바로 로딩으로 넘어간다.
- **봇의 출구 찾기 순서:** 문양이 보이면 문양 쪽 → 아니면 가장자리 출구 표시의 삼각형 방향 →
  둘 다 없으면 이 층에서 마지막으로 본 출구 방향 → 그것도 없으면 위/오른쪽/왼쪽/아래로 조금씩 둘러본다.

### NPC

- **전투가 끝나면 그 층에 NPC가 생길 때가 있다. 그러면 바로 다음 층으로 가지 말고 NPC한테 먼저 말을 건다 (F).**
- NPC는 머리 위에 이름표(예: "베아트리스", "포셔")가 있다. 가까이 가면 "F 대화"가 뜬다.
- F → 대화(Space로 넘김) → 선택지. 선택지는 클릭으로 고른다.
- 선택의 방(2층)에는 처음부터 NPC가 있다.
- 실험에서 본 선택지:
  - 베아트리스 "시약 테스트": 해보지 뭐!(돈 또는 HP 랜덤 변화) / 다음에!(30원)
  - 포셔 "너도 상품으로 팔릴 수 있어": 50원 내고 HP 20% 회복 / 최대 HP 30% 내고 랜덤 잠재력 1개
- 선택 뒤에 "아이템 획득!" 화면이 뜬다. 빈 곳을 클릭해서 넘긴다.

- NPC 이름표 위의 **초록 글자는 NPC 종류**다: "사건"(이벤트), "회복", "상점". 이름은 흰 글자.
  OCR이 "회복"을 "화복"으로 읽기도 해서, 봇은 글자 색으로 종류와 이름을 구분한다.
- 방에 들어가면 위쪽 가운데에 방 제목("선택의 방", "2/20층")이 잠깐 뜬다. 봇은 이걸 읽어서 층을 센다.
  제목의 "방" 글자 동그라미를 출구 문양으로 착각할 수 있어서, 제목이 떠 있는 동안은 출구를 찾지 않는다.
- 2층 선택의 방에는 처음부터 NPC(예: 베르주)가 있다. 선택의 방은 NPC와 이야기하기 전엔 나가지 않는다.

### 전투 끝 (사용자 설명, 2026-10-02)

- 전투가 끝나면 화면이 잠깐 일렁인 뒤 잠재력 선택이나 소리 획득이 뜬다. 소리는 항상 얻는다.
  → 봇은 **"소리 획득" 화면을 보면 전투 끝**으로 본다.
- 전투방(전투/강적/리더)에서는 전투가 끝나야 출구로 간다. 출구는 전투 중에도 보인다.
  150초 동안 소리 획득을 못 보면 진행 (봇을 층 중간에 켰으면 40초).
- 3층 NPC(650원 도박 포함)는 전투가 끝난 뒤에 생길 수 있다. 3층은 전투 끝 → NPC 확인 → 출구가 보인 뒤 8초 뒤에 재시작 판단.
- 오른쪽 위 "자동 전투" 아이콘은 칼/화살표가 번갈아 바뀌는 애니메이션이라 전투 여부 단서가 아니다.

### NPC 선택지 고르기 (사용자 규칙, 2026-10-01)

| 선택지 | 고를 것 |
|---|---|
| 체력을 깎는 대신 잠재력이나 돈을 얻는 것 | 무조건 그것 |
| 100원 받을래 / 30원 받을래 (+100, −100, +30, 아무 일 없음이 25%씩이라고 앎) | 6층 이하: 100원, 7층 이상: 30원 |
| 33% 확률로 잠재력 | 33% 쪽 |
| 소리를 90원/140원에 살래 / 30원 얻을래 | 30원 |
| 소리 5개 팔고 150원 / 30원 | 소리 팔고 150원 |
| 650원 도박 (1–3층에서만 나옴, 4층부터는 안 나옴) | 650원 쪽 (위 "650원 이벤트") |
| 공짜 소리 고르기 (X의 소리 5개 / Y의 소리 5개 / 랜덤 소리 5개) | X, Y가 협주스킬 활성화에 쓰는 소리면 그것 (많이 쓰는 것, 같으면 덜 가진 것), 아니면 랜덤. 협주 1개만 쓰는 소리도 랜덤보다 먼저, 단 그 소리가 이미 40개 이상이면 랜덤 (사용자 규칙 2026-10-02) |
| 그 밖의 선택지 | 봇이 질문과 고른 답을 기록해 두고, 사용자가 보고 알려준다 |

- 모르는 선택지는 잃는 것 없는 쪽(획득/회복만 있고 소모·차감·소실·랜덤 변화가 없는 것)을 고른다.
  전부 돈/소리가 드는 선택지(예: 소리 10개를 140원/90원에)는 ESC로 안 고르고 나온다 (안 닫히면 가장 싼 것).
- OCR은 코인 그림을 0으로 읽어 금액이 10배로 보인다 (30 → "300", 650 → "6500"). "획득"을 "획티"로 읽기도 한다.
- 650원 도박 결과는 화면 가운데 알림("200개를 잃었습니다")을 먼저 보고, 없으면 돈을 여러 번 읽어 가장 큰 값으로.

### 걷기 방식 (`stella_auto/pathing.py`, 2026-10-02 바꿈)

사용자 지적: "캐릭터를 생각없이 움직이지 말고", "파란색 마크랑 화살표를 보고 그쪽 방향으로 움직이고,
지금 화면에 들어온 지도를 보고 어디로 가야 할지 추론하도록. 찾은 출구는 기억에 저장해 두고."
예전 방식(목표 쪽으로 무작정 걷기, 막히면 옆으로 비키기, 안 보이면 사방 둘러보기)은 13층에서 책장 그림의
동그라미를 출구로 알고 같은 벽에 45걸음씩 두 번 박았다.

- **방 안 위치 (`odometry.py`)**: 카메라가 캐릭터를 따라가니까 배경이 밀린 만큼 캐릭터가 움직인 것.
  앞뒤 화면을 위상 상관으로 비교한다 (HUD, 캐릭터, 방 제목 자리는 가림). 로딩 뒤 첫 필드 화면이 (0, 0).
  - W+D 1.5초에 화면 기준 약 (+460, -370)px. 위아래가 좌우의 0.73배로 보여서 W+D는 화면에서 36도.
  - 300px 넘게 떨어진 화면끼리는 원근 때문에 잘 안 맞아서 걸을 때 초당 5번 넘게 잰다.
  - OpenCV 5.0.0 `phaseCorrelate`는 같은 입력에도 부를 때마다 결과가 달라서 numpy로 직접 계산한다.
- **방 지도 (`navmap.py`)**: 48px 칸. 서 있었던 칸, 막힌 칸(키를 1초 넘게 눌렀는데 그쪽으로 40px도 못 감
  → 앞 칸과 양옆 칸), 피할 곳(아직 나가면 안 될 때 출구 둘레 280px). A*로 막힌 칸을 피해 길을 찾는다.
- **출구 목표** (위에서부터):
  1. 화면 가장자리 출구 표시(문 아이콘)가 보이면 출구는 화면 밖. 화면 가운데→표시 방향으로 간다.
     이때 화면 안의 문양 비슷한 것은 무시한다.
  2. 표시가 없고 출구 문양이 보이면 그 자리. 문양 안쪽 색이 다음 방 종류와 맞아야 한다
     (전투 21, 선택 90, 리더 7, OpenCV 색상값. 강적/거래는 아직 못 잼).
  3. 이번에 본 출구 자리, 그다음 전에 이 지도에서 나갔던 자리.
- **둘러보기**: 8방향 중 막히지 않고 안 가 본 칸이 가장 많은 쪽으로 2.5초. 출구를 피해야 하면 출구 쪽 60도는 뺀다.
- **화면 보고 판단 (looks)**: 걸어 본 칸이 화면에 보이면 그 색(Lab)을 바닥 표본으로 모은다. 화면의 다른 칸은
  표본과 색이 비슷할수록 바닥 같다고 본다. 바닥 같지 않은 칸(벽, 책장, 가구)은 길 찾기에서 비싸게,
  둘러볼 때는 덜 쳐준다. 가짜 방 시험: 두꺼운 벽이 바닥과 다른 색이면 부딪힌 칸 11 → 2, 10.8초 → 5.5초.
  13층 실화면: 책장은 바닥 아님, 초록 바닥은 바닥으로 잘 나뉘지만 무늬가 알록달록한 바닥은 바닥 아님으로
  나오기도 한다 (그래서 막지는 않고 비싸게만 둔다. 밟아 보면 그 색도 바닥으로 배운다).
- **지도 기억 (`roommemory.py`, `data/rooms/`)**: 방마다 입구 화면(1/4 흑백), 출구 자리, 걸어 본 칸,
  막혔던 칸을 저장한다. 다음에 같은 입구 화면이 나오면(층마다 지도 2~3개, 사용자 설명) 알아보고 출구로 바로 간다.
  전에 막혔던 칸은 위치 재기가 조금 틀어질 수 있어서 막지 않고 비싸게만 본다.
- 로딩을 본 뒤에는 방 제목을 읽을 때까지(최대 5초) 움직이지 않는다. 안 그러면 지난 방 기준으로 걷는다.
- NPC 이름표는 흰 글자여야 한다 (실제 이름표 흰 픽셀 0.14~0.40, 바닥 무늬를 잘못 읽은 것 0.00).
- 출구 문양: 흰 고리를 못 찾으면 다음 방 색 고리로 찾는다 (15층 선택의 방 문은 하늘색 고리, 레벨 표시에 반쯤 가림).
  처음 본 문양은 화면을 한 번 더 보고 같은 자리에 있어야 믿는다.
- 시험 (2026-10-02 새벽, `--no-gamble`): 13층 → 20층을 혼자 감. 전투 끝난 뒤 출구까지 3~29초.
  16층(선택) 19초에 NPC 대화·선택지·카드·출구, 19층 거래의 방 상점 6개 + 강화머신 3번.

## 메뉴 이동 (실험에서 확인)

- 기록 상세 → Esc → 기록 관리 → Esc → 탐험 메뉴(폰 화면). "별의 탑 탐색" 카드 → 탑 목록.
- 탑 목록: 물과 그림자(빛/땅), 불꽃과 먼지(물/바람), 폭풍과 번개(불/어둠), 원초적 미로. 고르고 "별의 탑 들어가기".
- 난이도 선택 → "출발" → 팀 편성("프리셋 설정 완료" 표시, "다음") → 레코드 조합("전투 시작") → 1층.
  팀 편성과 레코드 조합의 "자동 편성"은 누르지 않는다.
- 레코드 조합 화면에 메인 레코드별 협주스킬 활성화 재료(소리)가 나온다.
- 카드 선택: 처음엔 왼쪽 카드가 골라져 있고 Space로 가져간다.
- 소리 획득 / 협주 스킬 활성화: Space로는 안 넘어간다. 빈 곳을 클릭한다. 가운데는 협주스킬 목록이라
  누르면 설명 창이 뜨니 오른쪽 아래 빈 곳(예: 1650, 860)을 누른다. 협주스킬이 여러 개 켜지면 한 장씩 차례로 뜬다.
- 소리 획득 화면에 협주스킬별 필요한 소리와 지금 개수가 전부 나온다 (예: 눈을 녹이는 봄바람 레벨1, 14/25, 10/25).

## 재시작

### 재시작 조건

- 1–3층 안에 650원 선택지가 안 나왔을 때
- 650원 선택지에서 실패했을 때 (70%)
- 6층까지 리롤을 10번 넘게 했을 때
- 한 번의 카드 선택에서 리롤을 연속 5번 이상 했을 때

### 재시작 방법 (영상 확인)

1. Esc → 지도 화면에서 "포기" (또는 Q)
2. "현재 별의 탑 진행도를 포기하시겠습니까?" → 확인 (또는 Space)
3. "탐색 완료" → 기록 화면
4. 휴지통(분해) → "현재 기록을 분해하면 다음 아이템을 획득합니다" → 확인
5. 난이도 선택 화면으로 돌아온다 → 출발

실험에서 1–5 전부 확인했다 (3층에서 650원 선택지가 안 나와서 재시작). 분해 확인 팝업에는 키 안내가 없어서
"확인" 버튼을 클릭한다. 포기 확인과 분해 확인은 둘 다 "안내" 팝업이라 글자로는 구분해야 한다.

중간에 포기한 기록은 저장하지 않고 바로 분해한다. 20층까지 끝낸 도자기만 "기록 저장"한다.

## 650원 이벤트 (1–3층)

- NPC: 분홍 머리, 뿔, 등불. 대사 "이게 바로...... 운명의 게임이지!"
- 선택지 3개 (영상 확인):

| 선택지 | 효과 |
|---|---|
| 이길 거야! | 50% 확률로 200 획득, 50% 확률로 100 차감 |
| **이길 수...... 있어?** | **30% 확률로 650 획득, 70% 확률로 200 차감** ← 이걸 고른다 |
| ......지지 마. | 30 획득 |

- 결과는 "200개를 잃었습니다" 같은 알림으로 뜬다.
- 퀴즈형 NPC 질문은 sstoy "별의 탑 정답지" 12문항으로 답한다.
  (sstoy `src/modules/app-summary.ts`의 `STAR_TOWER_QA_DATA`)
- NPC 선택지 화면 조작키: Space 확인, B 가방, Esc 돌아가기.

## 잠재력 카드

### 카드 표기 (영상 확인)

- 새 잠재력: `레벨 1`, `레벨 2`, `레벨 3`
- 이미 가진 잠재력: `레벨 3 ▸ 4`처럼 +1 업그레이드
- `레벨 1+2` 같은 보너스 표기도 있다 [? 의미]
- 색: 코어는 분홍, 일반은 보라(rarity 1)와 금(rarity 2). 보라가 금보다 조금 덜 나온다.
- 코어(분홍)는 Lv1이 끝이고 탑에서 반드시 고를 수 있어서 신경 안 쓴다.
- 선택 화면 조작키: Space 확인, B 가방, Z 설명 전환, Q 리롤. 위쪽에 "간단히" 토글이 있다.
- 게임 안 프리셋을 넣어두면 카드에 "6레벨 추천 5/6"처럼 목표 레벨과 지금 레벨이 뜬다 (영상 확인).
- 카드 선택은 레벨업("팀 N레벨 달성!") 말고도 선택의 방, 상점 잠재력 음료에서도 뜬다. 이때는 제목이 없다.
- 리롤은 40원. 횟수 제한은 없다 (재시작 조건은 위 참고). 실험에서 Q로 리롤되는 것 확인 (640 → 600원).
- 상점에서 잠재력을 살 때도 리롤 한두 번 할 돈(40–80원)은 남겨둔다.

### 표시의 뜻 (탑이 끝났을 때 기준)

| 표시 | 끝났을 때 |
|---|---|
| 필수 | 무조건 있어야 한다. 6레벨, 최소 5레벨 |
| 다다익선 (목표 6) | 어지간하면 있는 게 좋다. 없거나 1–3레벨이어도 버리진 않는다 |
| 다다익선 (목표 3) | 없어도 된다 |
| 명함만 | 무조건 있어야 한다 (1레벨 이상) |
| 후순위 | 없어도 된다 |

### 고르기 시작하는 층

| 표시 | 고르기 시작하는 층 |
|---|---|
| 필수 | 1층부터. 뜨면 무조건 가져간다 |
| 다다익선 (목표 6) | 1층부터 |
| 다다익선 (목표 3) | 13층부터 (2번째 상점 뒤) |
| 후순위, 명함만 | 19층부터 (3번째 상점부터) |

### 레벨 예산

- 새 잠재력 Lv3 카드는 한 판에 10번까지 가져갈 수 있다. 떴는데 안 집으면 횟수는 안 줄어든다.
  이 10번은 필수와 다다익선에 쓴다.
- Lv2 카드로 가져갈 수 있는 개수 = (필수 + 다다익선 개수) − 10.
  예: 필수가 12개면 10개는 Lv3로, 2개는 Lv2로 가져갈 수 있다.
- Lv1 카드는 19층부터 명함만/후순위일 때만 가져간다.

### 고르는 순서 (사용자 예시)

| 선택지 | 고를 것 |
|---|---|
| 필수 Lv2(새) / 필수 4▸5 / 다다익선 3▸4 | 필수 Lv2(새) |
| 필수/다다익선(6)의 Lv2·Lv3 새 카드 / 업그레이드 | 새 카드 |
| 필수 Lv2(새) / 다다익선(목표 6) Lv3(새) | 다다익선 Lv3 (200점 < 210점) |
| 필수 Lv2(새) / 다다익선(목표 3) Lv3(새) | 필수 Lv2 |
| (19층+) 후순위 Lv2(새) / 필수·다다익선 업그레이드 | 업그레이드 |
| (19층+) 후순위 Lv2(새) / 후순위 1▸2 / 다다익선(목표 3) 2▸3 | 후순위 Lv2(새) |
| 보라 Lv3 / 금 Lv3 (나머지 같음) | 보라 |
| 보라 Lv2 / 금 Lv3 | 금 (레벨을 색보다 먼저 본다) |
| [필수 Lv2, 쓸모없는 Lv1, 쓸모없는 Lv1] (초반) | 리롤해도 되고 필수 Lv2를 집어도 된다 |
| 집을 게 없음 | 리롤. 저층에선 후순위를 집느니 리롤한다 |

**안전장치:** 필수가 아직 0레벨인데 13층을 넘으면, 그 필수는 다른 카드보다 먼저 집는다.
단 Lv1은 절대 안 집는다. Lv2 이상만.

## 상점 (4번: 5, 12, 19, 20층)

### 봇의 거래의 방 순서 (`stella_auto/runner.py`, `stella_auto/shop.py`)

1. 노란 강화머신 위 초록 "강화" 글자 쪽으로 걸어가 "F 강화"가 뜨면 F. 180원까지 반복, 카드는 점수 + 캐릭터 순서로.
2. 초록 "상점" 글자가 붙은 NPC(포셔)에게 F → 상점.
3. 상점 화면 읽기: 큰 가격 숫자는 OCR이 깨뜨려서, 상품 이름(종류)과 빨간 딱지 모양(동그라미 = 할인,
   알약 = 품절)으로 정해진 가격표에서 고른다: 음료 200/160/100, 소리×5 90/72/45, 소리×15 400/320/200.
4. 상점에 들어가면 먼저 B(가방) → 레코드 스킬 탭에서 협주스킬마다 필요한 소리(그림 색)와 가진 개수를 읽고
   ESC로 돌아온다 (`stella_auto/notes.py`). 상점 소리 상품 종류는 이름(못 읽으면 그림 색)으로 안다.
5. 살 것: 할인 음료 → 소리 (아래 "소리" 기준) → (1000원 넘게 남으면) 정가 음료. 카드 리롤용 80원은 남긴다.
   마지막 상점(20층)은 남은 돈으로 소리까지 다 산다 (쓰는 협주스킬이 많은 소리부터).
   상품을 누르면 구매 팝업 → Space. 음료는 카드 선택으로 이어진다.
   큰 새 가격만 따로 읽는다 (넓게 읽으면 옛 가격과 섞여서 45원을 72원으로 알았다).
6. 2·4번째 상점은 할인 상품을 산 뒤 새로고침(Q) 한 번. 끝나면 Esc.
7. 강화/상점이 끝나야 출구로 간다 (150초 넘으면 그냥 나감). 20층은 보스를 잡은 뒤 마지막 상점에 들른다.
8. 강화머신/상점 NPC 앞에 섰던 자리를 지도에 기억해, 같은 지도(5·12·19층은 같은 지도였다)에선 바로 간다.

### 강화머신

- 가격: 1번째 상점은 0 → 60 → 120 → 180. 2·3·4번째 상점은 60부터 시작.
- 180원까지는 누른다. 그러니까 1번째 상점은 4번, 나머지는 3번.
- 강화하면 카드 3장 중 1장을 골라 강화한다.
  - 레벨 1당 점수가 높은 카드를 먼저 고른다 (필수 100 > 다다익선(6) 70 > 다다익선(3) 30 > 후순위 5).
  - 점수가 같으면 프리셋의 캐릭터 우선순위를 따른다. 사용자가 적는다
    (`python -m stella_auto.preset "<링크>" --priority 엘레노어,안즈,레이스`).
  - 예: 바람 프리셋(레이스 메인, 엘레노어, 안즈)은 엘레노어 > 안즈 > 레이스.
    메인 캐릭터 잠재가 제일 잘 뜨고, 레이스는 총 20 이상이면 충분하지만 엘레노어는 많을수록 좋아서.
- 흐름 (영상 확인): 필드에서 강화머신을 쓰면 "N 소모, 잠재력 강화 성공" → 카드 3장 고르는 화면 →
  한 장 고르면 필드로 돌아온다. 머신 위에 다음 가격이 뜬다.
- 강화는 보통 +1이고, 가끔 +2짜리가 뜬다. +2는 한 판에 5번까지 고를 수 있고, 5번 고르면 더 안 뜬다.
  (영상 속 강화 미리보기는 전부 +2였다: 3▸5, 4+3▸6+3, 2▸4, 1▸3, 5▸6은 6에서 멈춤)
- 예전 메모의 "30% 확률로 +2"는 잘못 섞인 것. 30%는 650원 선택지 확률이다.
- 가진 잠재(코어 빼고)가 전부 6레벨이면 강화머신을 눌러도 카드가 안 나오고 돈도 안 든다 (2026-10-02 07:18 19층).
  봇은 이럴 땐 강화머신에 가지 않는다 (사용자 지적).

### 잠재력 상품

- 할인하는 잠재력 상품은 전부 산다.
- 할인 상품(잠재력과 소리)을 다 사고도 1000원 이상 남으면 200원짜리 잠재력 상품도 산다.
- 마지막 상점(20층)에선 돈이 안 남게 200원짜리까지 사서 다 쓴다.

### 상점 리롤

- 4번의 상점을 통틀어 2번 리롤할 수 있다. 새로고침 버튼에 "남은 횟수"와 가격(영상에선 100원)이 뜬다.
- 지금 방식: 2번째와 4번째 상점에서, 할인 상품을 다 산 뒤에 리롤. 최적인지는 모름.

### 소리

- 협주스킬은 6개. 필요한 소리와 지금 개수는 게임 안에서 확인한다:
  가방(B) → "레코드 스킬" 탭. 위쪽에 소리 9종의 개수, 아래에 협주스킬별 필요량(`14/10` 같은 표기).
- 구매 기준 (협주스킬에 필요한 소리만):

| 상품 | 기준 |
|---|---|
| 5개 45원 (50% 할인) | 무조건 산다 |
| 5개 72원 (20% 할인) | 그 소리가 이미 너무 많지 않으면(41개 이상?) 산다 |
| 5개 90원 (정가) | 협주스킬 4개 이상에 공통으로 필요하면 산다. 단 그 소리만 40개쯤 있고 나머지가 20개 미만이면 안 산다 |
| 15개 200원 (50% 할인) | 협주스킬 2개 이상에 공통일 때만 산다 |
| 15개 320원, 400원 | 절대 안 산다 |

- 바람 프리셋 협주스킬 6개가 쓰는 소리 (12층에서 읽음): 바람 6개, 필살기 3개, 강공 3개, 행운 2개, 집중 1개.
- 소리 9종 그림 색과 이름은 `stella_auto/notes.py` 맨 위 표. 초록 하트는 체력의 소리 (20층 상점 이름과 그림 색이 맞음), 하늘 물방울은 아직 이름을 모른다.
- 72원의 "41개 이상"은 그 소리를 가진 개수로 해석했다. 협주스킬 필요량을 못 읽으면 45원짜리만 산다.

- 화면이 바뀌는 중인 프레임은 엉뚱하게 판정될 수 있다 (예: 구매 팝업이 커지는 중에 "대화"로 보임).
  같은 화면이 3번 연속 나와야 인정하고, 그 전에는 아무것도 누르지 않는다.

## 도자기 점수

완성된 도자기(20층까지 끝낸 기록)를 이 점수로 비교한다. 코드: `stella_auto/score.py`.
배율은 앞으로 같이 조절한다.

| 항목 | 점수 |
|---|---|
| 필수 (보라/금 구분 없음) | 레벨 × 100 |
| 다다익선 (목표 6) | 레벨 × 70 |
| 다다익선 (목표 3) | 레벨 × 30 |
| 후순위 | 레벨 × 5 |
| 협주스킬 | 활성화 레벨 총합 × 250 (6개 가치는 같다고 본다) |
| 소리 | 1개당 1 |
| 도자기 평점 레벨 | 31 이상 +200, 30 이하 −200 (31 이상이면 공격력 버프) |

- 잠재력은 6레벨까지만 센다. 7–9레벨은 탑 밖 아이템으로 올리는 거라 도자기 가치에서 뺀다.
  목표 레벨은 넘어도 6까지는 센다 (다다익선(목표 3)이 5레벨이면 5 × 30 = 150).
- 명함만이 없거나, 필수가 하나라도 0레벨이면 점수와 상관없이 버린다.
- 코어(분홍)는 점수에 넣지 않는다.
- 도자기 평점은 잠재 개수 + 협주스킬 활성화 + 소리 개수로 정해진다 (프리셋과 무관). 협주스킬이 가장 많이 올려준다.
- 소리의 가치 근거: 협주스킬 1레벨에 소리 30–45개 ≈ 432–648원 ≈ 잠재 3개 ≈ 250점.
- 기록 상세 화면에 점수 계산에 필요한 숫자가 다 있다: 왼쪽 위 평점 레벨, 소리 9종 개수, 협주스킬별 레벨.

## 탑이 끝난 뒤 기록 저장 (2026-10-02 실험으로 확인, `stella_auto/record.py`)

1. 20층이 끝나면 "탐색 완료" → 빈 곳 터치 → 기록 화면.
2. 이름 옆 연필 → "이름 변경" 창 → 이름 칸 → 입력 → 확인. 이름에는 숫자/글자/밑줄만 들어간다
   (점, 띄어쓰기, 쌍점은 지워진다).
3. "기록 저장" → "기록 저장 성공" → 확인 → 난이도 선택 화면 → 봇이 다시 출발.
- 사용자 규칙 (2026-10-02): **기록 이름은 저장한 시각** (`1002_0158` = 10월 2일 01:58).
- 사용자 규칙 (2026-10-02 11시): **버릴 조건(필수/명함만 0레벨)인 판은 저장하지 않고 기록 화면에서 바로 분해한다.**
  "원하는 건 최고 점수 도자기 하나라 조건 미달 도자기는 가차 없이 깨도 된다." 장부(`logs/records.jsonl`)에는
  이름 "(분해)"로 남긴다. 봇이 1층부터 본 판만 (중간에 켠 판은 잠재 레벨을 다 몰라서 저장한다).
  장부의 잠재 레벨은 봇이 판 내내 기억한 것이다
  (기록 화면 카드 레벨 숫자는 OCR이 잘 못 읽음). 평점 레벨, 협주스킬 레벨은 기록 화면에서 읽는다.
- 포기를 누르지 않았는데 기록 화면이 보이면 분해하지 않고 저장한다 (끝까지 간 판).

## 기록 보관 (최대 100개)

- 가는 길 (2026-10-02 확인): 난이도 선택(출발 화면) → 왼쪽 위 뒤로 → 탑 고르는 화면 → 뒤로 → "별의 탑" 허브
  (휴대폰 화면: 별의 탑 탐색, 기록, 프리셋) → "기록" (1080, 875) → 기록 관리. 오른쪽 위에 "37/100"처럼 개수.
  돌아갈 때: 뒤로 → 허브 → "별의 탑 탐색" (1165, 700) → "별의 탑 들어가기" (1420, 900) → 출발 화면 (난이도 8 그대로).
- 2026-10-02 새벽 기록 37/100.
- 봇은 `logs/pause_at_menu` 파일이 있으면 다음에 출발 화면에서 멈춘다 (메뉴에서 할 일이 있을 때).

- 로비 → 별의 탑 탐색 → 기록 관리. 저장 시간/평점 정렬, 필터(원소: 물/불/땅/바람/빛/어둠), 분해 모드가 있다.
- 지금은 바람 도자기를 만드니까 필터를 바람으로 건다.
- 봇이 저장하는 기록은 이름을 저장한 시각으로 바꾼다 (2026-10-02 사용자가 "자동 {점수}"에서 바꿈).
  정리할 때는 이 이름 꼴의 기록만 건드린다. 원래 있던 기록은 손대지 않는다.
- 하트(선호) 누른 기록은 절대 분해하지 않는다. 사용자가 잠금+하트로 보관하는 기록: `1002_0158`.
- 사용자 규칙 (2026-10-02 14시): **봇이 관리(분해)하는 기록은 `mmdd_hhmm` 이름인 것만.** "이름 없는 기록"을 비롯한 다른 이름의 기록은 깨지 않는다.
- 분해하는 법 (2026-10-02 사용자 영상): 기록 관리 → 오른쪽 위 "분해" (1575, 63) → 분해 모드 (아래에 "선택됨 0/N",
  "기록 분해"). 잠긴 카드는 먼저 카드 오른쪽 위 자물쇠를 눌러 풀고(안 풀면 "잠긴 기록이므로 분해할 수 없습니다"),
  카드를 누르면 빨간 테두리로 골라진다. "기록 분해" (1710, 1002) → "선택한 기록을 분해하면..." 또는
  "희귀도가 다소 높은 기록을 선택하셨습니다..." → 확인 (1170, 792).
- 카드 자리 (저장 시간 정렬, 분해 모드): 4열 x 2행이 보인다. 이름 칸 왼쪽 위 (195+435*열, 180+465*행),
  자물쇠 (492+435*열, 202+465*행), 카드 몸통 (313+435*열, 375 또는 770).
- 2026-10-02 11시: 사용자가 0514, 0427, 0350, 이름 없는 기록(02:36)을 깼고, 봇이 0551~0845의 버릴 조건 7개를 깸 → 37/100.
  남은 봇 기록은 `1002_0908`(조건 통과). "이름 없는 기록" 6개(평점 30~32, 바람 팀)는 장부에 없어 판단을 못 해서 그대로 둠.
